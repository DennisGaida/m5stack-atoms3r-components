# Documentation Directory

This directory contains documentation assets and design files for the M5Stack AtomS3R project.

## Directory Structure

```
docs/
├── images/          # Photos and screenshots
│   └── (add your device photos here)
└── design/          # Design files and mockups
    └── display-mockup.psd
```

## Suggested Images to Add

Consider adding photos of your working device to help users understand the project:

### Device Photos
- `m5stack-atoms3r-device.jpg` - The physical M5Stack AtomS3R device
- `m5stack-atoms3r-back.jpg` - Back view showing connectors

### Display Screenshots
- `display-free.jpg` - Display showing "Available" status
- `display-meeting.jpg` - Display showing "Busy/Meeting" status
- `display-dnd.jpg` - Display showing "Do Not Disturb" status

### Using Images in Documentation

Once you add images, reference them in your main README:

```markdown
## Hardware

![M5Stack AtomS3R](docs/images/m5stack-atoms3r-device.jpg)

*M5Stack AtomS3R showing Teams presence status*
```

## Design Files

The `design/` directory contains source files used for creating graphics and mockups:

- `display-mockup.psd` - Photoshop mockup of the display layout

These files are useful for:
- Designing new display layouts
- Creating documentation graphics
- Understanding the visual design process
